# Computer Vision Module (CV)

> **Status**: Planned (Phase 2 & 3)

This directory will contain Python-based Computer Vision pipelines utilizing OpenCV, PyTorch, and geometric 3D vision algorithms.

## Planned Submodules
- `depth_estimation/` - Monocular / RGB-D depth inferencing (e.g., ZoeDepth / MiDaS)
- `plane_detection/` - Wall, floor, ceiling plane RANSAC and structural polygon extraction
- `spatial_calibration/` - Camera intrinsic/extrinsic parameter matrix computation
- `object_detection/` - 3D bounding box detection for persistent room elements (doors, windows)
