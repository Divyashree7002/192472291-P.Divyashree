# Machine Learning Module (ML)

> **Status**: Planned (Phase 3 & 4)

This directory will contain the recommendation engines, constraint solvers, and explainable AI modules.

## Planned Submodules
- `constraint_solver/` - Spatial clearance, doorway swing arc, and circulation corridor constraint verification
- `recommendation/` - Multi-criteria ranking and preference matching model (scikit-learn & PyTorch)
- `budget_optimizer/` - Cost estimation and Pareto-optimal furniture selection
- `explainability/` - Transparent rationale generator for layout and style decisions
